# Oravi Lux 3D emblem

Standalone Three.js studio that extrudes the original `logo.svg` paths into a champagne-gold metal badge. The SVG is not redrawn.

```bash
cd 3d-logo
npm install
npm run dev
```

Open the local URL Vite prints (port 5174). Drag to orbit. Use the panel for depth, bevel, metal, roughness, light, background, and camera views.
