# Oravi Lux

Premium marketing website for **Oravi Lux**, an executive concierge and corporate hospitality company.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build for production

```bash
npm run build
npm start
```

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Motion (scroll reveals)
- Phosphor Icons
